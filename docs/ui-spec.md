# 春风画布 · 界面规格（对齐 hb.c0c.cc）

> 依据：2026-11-16 实拍 hb.c0c.cc 的 5 个页面 + 从其 3.7MB bundle 提取的 i18n 与路由。
> 路由实证：`/`、`/canvas`、`/canvas/:id`、`/image`、`/video`、`/prompts`、`/assets`、`/config`

---

## 0. 全局外壳

**顶栏**（高 64px，全宽，底部 1px 描边）

```
[logo] 无限画布 │ ↗ 我的画布 │ ▣ 生图工作台 │ ▷ 视频创作台 │ ▤ 提示词库 │ ▦ 我的资产 │ ⚙ 配置 │ …… [插件][面板][同步][中] v0.20.0 [?]
```

- 左：三角 logo + 产品名，字号 15px 中等
- 中左：6 个导航项，**每项都是「图标 + 文字」**，当前页有底部白色下划线（2px）
- 右：4 个图标按钮（插件市场 / 侧栏 / 同步 / 语言），版本号小字，帮助圆图标
- 背景 `--bg`，导航项未选中 `--muted`，选中 `--fg`

**画布底色**：整页点阵网格（点 1px，间距约 28px），是页面的底，不是画布专属。

## 2. 画布编辑器 `/canvas/:id`

> 从 bundle 实证：左侧工具栏项 = `select / pan / focus / text / image / video / audio / config / group / extensions / upload / appearance / clear`；
> 底部 composer 类名 = `canvas-composer-mode-button` / `canvas-composer-model-picker` / `canvas-composer-tools`；
> 另有 `zoomSlider` / `miniMap` / 节点 `controls: ratio, duplicate, delete, images, texts, generations, reasoning`。

```
┌ 顶栏 ────────────────────────────────────────────────────────────┐
├────┬─────────────────────────────────────────────────────────────┤
│ 工 │                                                             │
│ 具 │                     画布（点阵底）                            │
│ 栏 │                     节点 · 连线                              │
│    │                                                             │
│ 选 │                                            ┌───────────┐    │
│ 择 │                                            │ 缩略图     │    │
│ 移 │                                            └───────────┘    │
│ 动 │      ┌──────────────────────────────────────────────┐       │
│ 居 │      │ [模式▾]  提示词输入…  @引用   [模型 ▾]  [工具] │      │
│ 中 │      └──────────────────────────────────────────────┘       │
│ …  │  ──────●───────  缩放滑杆                        45%         │
└────┴─────────────────────────────────────────────────────────────┘
```

**关键（我上一版做错的地方）**：
- **提示词输入在底部 composer**，不在右侧面板。选中节点后，composer 变成该节点的提示词输入框，带「生成 / 停止」。
- composer 里有 **模型选择器**（胶囊形，h-8，图标+模型名）—— 这就是「默认模型」的落点。
- composer 支持 **`@` 引用已连接的素材**（参考图/文本/组），引用会重新编号。
- 选中节点时出现**浮动工具条**：比例 / 复制 / 删除 / N 张 / N 个备选 / N 次生成 / 推理强度。
- 右下角缩略图，左下角缩放滑杆。
- **没有右侧固定面板**。

## 4. 提示词中心 `/prompts`

```
                    提示词中心
                 当前共 0 条提示词

分类         │  ┌──────────────────────────────────────────┐
[全部]       │  │ 搜索标题、内容或标签                        │
             │  └──────────────────────────────────────────┘
标签         │
[全部]       │              （列表 / 空态 / 无限滚动加载）
```

- 标题与计数**居中**
- 左侧筛选栏：**分类**、**标签** 两组，每组是胶囊 chips（全部/…），与主区之间有一条 1px 竖分隔线
- 主区：搜索框（占满宽，圆角、内嵌放大镜）
- 列表从「提示词来源」加载，**分页/无限滚动**（`loadMore`、`end`）
- 每条提示词有：分类、标签、标题、内容，操作为「使用此提示词」

## 6. 配置 `/config`

```
配置与用户偏好
渠道聚合、模型选择、同步与本地存储

JSON 文件包含 API Key 和 WebDAV 凭据，请妥善保管。      [ 导入配置 ] [ 导出配置 ]

渠道 │ 本地代理 │ 偏好设置 │ 提示词来源 │ WebDAV │ 本地存储
────────────────────────────────────────────────────────
每个渠道选择一个协议并拉取模型，为每个模型指定能力              [ + 新增渠道 ]
（生图/视频/文本/音频），并可自定义调用脚本。

┌──────────────────────────────────────────────────────┐
│ 默认渠道                              [编辑] [删除]   │
│ OpenAI · 4 个模型 · https://api.openai.com            │
└──────────────────────────────────────────────────────┘
```

- 六个标签：**渠道 / 本地代理 / 偏好设置 / 提示词来源 / WebDAV / 本地存储**
- 渠道卡片：名称 / 协议 · N 个模型 · baseUrl，右侧编辑与删除
- 新增渠道：选协议（OpenAI / Gemini）→ 填 baseUrl 与 Key → 拉取模型 → **为每个模型勾选能力**（生图/视频/文本/音频）
- 偏好设置：默认生图模型、默认分辨率、画布默认生图张数等

## 7. 配色：改用 DSH 主题令牌

这是第 1 条问题的修法。**不再用自造的 Kiln 深色盘**，改为像 `dsh-chunfeng` 那样全部走 DSH 别名令牌，跟随 DSH 深浅色：

| 语义 | 令牌 |
|---|---|
| 页面底 | `--dsw-alias-bg-base` |
| 卡片/面板 | `--dsw-alias-bg-layer-2` |
| 主文字 | `--dsw-alias-label-primary` |
| 次文字 | `--dsw-alias-label-secondary` |
| 弱文字 | `--dsw-alias-label-tertiary` |
| 描边 | `--dsw-alias-border-l2` / `-l4` |
| 主按钮 | `--dsw-alias-button-primary-fill` |
| 链接/强调 | `--dsw-alias-link` |
| 悬停 | `--dsw-alias-interactive-bg-hover` |

**连带后果**：去掉自造的深/浅色切换（跟随 DSH），去掉 Hallmark Kiln 主题。

## 8. 与现版的差异清单

| 现版 | 目标 |
|---|---|
| 单页画布 | 5 页 + 顶栏导航 |
| 左侧工具栏 + **右侧面板** | 左侧工具栏 + **底部 composer**，无右侧面板 |
| 提示词塞在右侧面板 | 独立提示词中心页（分类/标签/搜索/来源） |
| 模型是硬编码 4 条 | 渠道 → 模型 → 能力，设置页可配 |
| Kiln 深色盘 + 自造主题切换 | DSH 令牌，跟随宿主深浅色 |
| 出图是本地占位 | 真调接口出图（Host 侧 + 密钥存储） |
| 无默认模型概念 | 偏好设置里的默认生图模型 / 分辨率 / 张数 |
